# Расписание Очереди (Material Design)

Менеджер расписания очереди для Артёма и Максима.

## Как безопасно обновлять проект на VPS через GitHub без потери данных

Архитектура хранения данных настроена таким образом, что файл базы данных (`database.json`) находится в `.gitignore` и **не отслеживается** git.

Это означает, что при выполнении `git pull` ваши реальные данные не будут перезаписаны, удалены или сброшены.

**Инструкция по обновлению на сервере (VPS):**

1. Перейдите в папку проекта:
   ```bash
   cd ~/musor
   ```
2. Скачайте новые изменения с GitHub:
   ```bash
   git pull
   ```
3. Установите новые зависимости (если они появились):
   ```bash
   npm install
   ```
4. Соберите обновленный клиент и сервер:
   ```bash
   npm run build
   ```
5. Перезапустите приложение (используя ваш менеджер процессов, например PM2 или systemd):
   ```bash
   pm2 restart server  # или npm run start, или systemctl restart
   ```

**Важно:** 
- Никогда не удаляйте файл `database.json` вручную, если не хотите потерять данные.
- Тестовые (демо) данные загружаются только в том случае, если файла `database.json` вообще не существует (при первом самом запуске сервера).

## Резервное копирование и восстановление (Backup)

Для дополнительной безопасности система автоматически создает резервную копию базы данных при каждом запуске/перезапуске сервера.
Копия сохраняется в файл `database.backup.json` (он также не отслеживается Git).

**Как восстановить данные из резервной копии:**

Если `database.json` был случайно повреждён или удалён, вы можете легко вернуть предыдущую рабочую версию:

1. Остановите сервер:
   ```bash
   pm2 stop server  # или ваш аналог
   ```
2. Удалите повреждённую базу (если она есть):
   ```bash
   rm database.json
   ```
3. Восстановите базу из бэкапа:
   ```bash
   cp database.backup.json database.json
   ```
4. Снова запустите сервер:
   ```bash
   pm2 start server  # или ваш аналог
   ```
